# Ardham AI - Universal Website & App Explainer

Mana anukunna AI tool - Edaina website / app link isthe, dani complete ga study chesi, safe a, ela vadali, better alternatives enti ani mana language lo cheppedi.

## Features
- ✅ Safe & Secure Check (SSL, domain age, privacy risk)
- ✅ World Multi-Language Translate (Telugu, Hindi, English, Spanish, etc)
- ✅ Ask Anything - App gurinchi em adigina answer
- ✅ Useful Filter - Better & useful alternative sites
- ✅ Login System - Google + Phone OTP (Firebase)
- ✅ Background Work - Offline + Online cache
- ✅ Voice Guide - Step-by-step voice in Telugu
- ✅ PDF Export

## Tech Stack
- Frontend: React + Tailwind + Vite
- Backend: FastAPI + LangChain + Playwright
- AI: OpenAI GPT-4 / Muse for summarization
- Auth: Firebase Auth
- DB: Firebase Firestore

## How to Run

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
